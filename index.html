Part 1 • Isotopes

What is an Isotope?

Definition

Isotopes are different versions of the same element. They have the same number of protons, but a different number of neutrons.

  • Same Atomic Number (Z) → same element, same chemical behaviour.
  • Different Mass Number (A) → heavier or lighter nucleus.
  • Naming rule: Element name – Mass number (e.g. Carbon-12, Carbon-14).
  • Some isotopes are stable; others are radioactive.

Shorthand Notation & Subatomic Particles

Reading Shorthand Notation

Mass Number (A) Protons + Neutrons (always the bigger number)
Atomic Number (Z) Number of Protons (finds the element on the Periodic Table)
146 C
Chemical Symbol (X) 1 or 2 letters from the Periodic Table
Protons = Atomic Number (Z)
Neutrons = Mass (A) − Protons (Z)
Electrons = Protons (neutral atom)

Example: Carbon-12 vs. Carbon-14

Subatomic Particle Carbon-12 (126C) Carbon-14 (146C)
Number of Protons 6 6
Number of Neutrons 12 − 6 = 6 14 − 6 = 8
Number of Electrons 6 6
⚡
Watch out for Ions! (Worksheet 1, Q3c)

A neutral atom has equal protons and electrons (p⁺ = e⁻). If p⁺ ≠ e⁻, the particle has an overall charge and is called an ion.

Strategy: Both columns in each box are isotopes of the same element (same protons!). Use p + n = Mass and n = Mass − p.

Look up Chromium (Cr) on Periodic Table → Z = 24

Example B: Reverse Lookup (p = 25, n = 27 & 25)

Which element has Z = 25? Add p + n for the name!

  • Z = 25 → Manganese (Mn)
  • Col 1: 25 + 27 = 52 → Manganese-52 (e = 25)
  • Col 2: 25 + 25 = 50 → Manganese-50 (p = 25, e = 25)

Part 2 • Radioactive Decay

Stable vs. Unstable Isotopes

Why Do Some Nuclei Decay?

Inside the nucleus, neutrons act like nuclear glue keeping positively charged protons from pushing apart.

  • Stable isotopes have a balanced proton-to-neutron ratio and do not change over time.
  • Unstable isotopes (often heavier ones with too many neutrons) break down over time.
  • An unstable, radioactive isotope is called a radioisotope.
Radioactive Decay: When an unstable nucleus emits radiation and breaks down to form a more stable nucleus (usually a different element).

The Three Types of Radiation

α

Alpha Radiation

Heavy particle made of 2 protons + 2 neutrons (helium nucleus, 42He).

β

Beta Radiation

Fast-moving electron (0−1e) fired when a neutron turns into a proton.

γ

Gamma Radiation

High-energy electromagnetic wave (γ) — no mass, no particle emitted.

Type 1 • Alpha (α) Decay

Alpha Decay: Ejecting a Helium Nucleus

Emitted 2 Protons + 2 Neutrons (42He)
Mass Number (A) Decreases by 4 (−4)
Atomic Number (Z) Decreases by 2 (−2) → New Element!
Nuclear Equation
23892U → 23490Th + 42He
Top: 238 = 234 + 4 ✓ Bottom: 92 = 90 + 2 ✓
Type 2 • Beta (β) Decay

Beta Decay: A Neutron Becomes a Proton

What happens? 1 Neutron → 1 Proton + 1 Fast Electron (0−1e)
Mass Number (A) Stays unchanged (0)
Atomic Number (Z) Increases by 1 (+1) → New Element!
Nuclear Equation
4219K → 4220Ca + 0−1e
Top: 42 = 42 + 0 ✓ Bottom: 19 = 20 + (−1) ✓
Type 3 • Gamma (γ) Decay

Gamma Decay: Releasing Pure Energy

Emitted High-energy electromagnetic wave (γ) — no particle!
Mass Number (A) Stays unchanged
Atomic Number (Z) Stays unchanged → Same Element!
Nuclear Equation
12553I → 12553I + γ
Top: 125 = 125 ✓ Bottom: 53 = 53 ✓

Q2

Spot Alpha, Beta, or Gamma

3-Second Shortcut: Look straight at the emitted symbol on the far right!

See ⁴₂He → Alpha
See ⁰₋₁e → Beta
See γ → Gamma
Example: 2a) ¹⁴₆C → ¹⁴₇N + ⁰₋₁e

Emits ⁰₋₁e, atomic number goes up 6 → 7, mass stays 14 ⇒ Beta decay.

Q3

Missing Numbers (The Arrow = "=")

Golden Rule: Treat the arrow (→) like an equals sign (=). Both top and bottom rows must add up equally!

Tricky One! Q3b: __Sr → ⁹⁰₃₉Y + ⁰₋₁e

Careful with the negative sign on −1!

  • Top: 90 + 0 = 90
  • Bottom: 39 + (−1) = 38 → ⁹⁰₃₈Sr

Real-World Applications

How We Use Radioisotopes Every Day

🏥
Cobalt-60 • Gamma (γ)

Cancer Radiotherapy

Focused beams of high-energy gamma rays penetrate tissue to target and destroy rapidly dividing cancer cells.

🔧
Sodium-24 • Beta & Gamma

Detecting Pipe Leaks

Added to fluid in underground pipes. Where radiation spikes at the surface, engineers pinpoint the leak without digging up the whole street.

🏺
Carbon-14 • Beta (β)

Dating Historical Artefacts

Living organisms absorb Carbon-14. After death it decays steadily into Nitrogen-14 — measuring what's left tells us an artefact's age.

🚨
Americium-241 • Alpha (α)

Home Smoke Alarms

Alpha particles ionise air to create a tiny electric current. Smoke absorbs the alpha particles, breaking the current and sounding the alarm!
