## Worksheet 1: Isotopes — Complete Answer Key

### Question 1: Fill in the Missing Information

**How to teach the approach:**
- Both columns in every box are isotopes of the **same element**, so they have the **exact same number of protons** (and electrons, since these are neutral atoms).
- **Given the name** (e.g., Chromium-58): Find $Z$ on the Periodic Table → $p = Z$, $e = Z$, and $n = \text{Mass} - p$.
- **Given $p$ and $n$** (e.g., $p = 25, n = 27$): Look up $Z = 25$ on the Periodic Table for the element name, then add $p + n$ for the mass number.
- **Given $e$** (Box 10, $e = 53$): In a neutral atom, $p = e = 53$ (Iodine).

### Question 3: Four Particle Diagrams

- **Diagram counts:**
  - **A:** 4 protons, 3 neutrons, 4 electrons (neutral Beryllium-7)
  - **B:** 4 protons, 4 neutrons, 4 electrons (neutral Beryllium-8)
  - **C:** 5 protons, 5 neutrons, 2 electrons (Boron-10 ion, $+3$)
  - **D:** 3 protons, 4 neutrons, 2 electrons (Lithium-7 ion, $+1$)
- **3a) Atomic number of particle A:** **4** (atomic number = number of protons).
- **3b) Mass number of particle C:** **10** (mass number = protons + neutrons = $5 + 5 = 10$).
- **3c) Explain which two particles are ions:**
  > **Particles C and D are ions.** An ion is a charged particle that has an unequal number of protons and electrons. Particle C has 5 protons and 2 electrons (net $+3$ charge), and Particle D has 3 protons and 2 electrons (net $+1$ charge). Particles A and B both have equal protons and electrons (4 each), so they are neutral atoms.

## Worksheet 2: Radioactive Decay — Complete Answer Key

### Question 1: Fill in the Blanks

1. **Radioactive decay:** "...when an **unstable** nucleus emits radiation and breaks down to form another **element**."
2. **Alpha decay:** "...made up of two **protons** and two **neutrons** (The same as a helium atom). This means that the atomic number of the atom decreases by **2** and the mass number **decreases** by 4."
3. **Beta decay:** "...atomic number **increases** by 1, [but] the **mass number** remains unchanged."
4. **Gamma decay:** "...there is no **particle** emitted from the nucleus, instead it's just a high-energy **wave**."

### Question 2: Identify Alpha, Beta, or Gamma Decay

**3-Second Strategy:** Check the emitted symbol on the right ($^4_2\text{He} = \alpha$, $^0_{-1}\text{e} = \beta$, $\gamma = \gamma$) and verify how $A$ and $Z$ change.

- **2a)** $^{14}_{6}\text{C} \rightarrow ^{14}_{7}\text{N} + ^{0}_{-1}\text{e}$ → **Beta decay**
- **2b)** $^{234}_{90}\text{Th} \rightarrow ^{234}_{90}\text{Th} + \gamma$ → **Gamma decay**
- **2c)** $^{99}_{43}\text{Tc} \rightarrow ^{99}_{43}\text{Tc} + \gamma$ → **Gamma decay**
- **2d)** $^{239}_{94}\text{Pu} \rightarrow ^{235}_{92}\text{U} + ^{4}_{2}\text{He}$ → **Alpha decay**
- **2e)** $^{226}_{88}\text{Ra} \rightarrow ^{222}_{86}\text{Rn} + ^{4}_{2}\text{He}$ → **Alpha decay**
- **2f)** $^{131}_{53}\text{I} \rightarrow ^{131}_{54}\text{Xe} + ^{0}_{-1}\text{e}$ → **Beta decay**

### Question 3: Fill in the Missing Pieces

**Golden Rule:** Treat the arrow ($\rightarrow$) like an equals sign ($=$). Top numbers (Mass $A$) must balance on both sides; bottom numbers (Atomic $Z$) must balance on both sides.

- **3a)** $^{241}_{95}\text{Am} \rightarrow ^{\mathbf{237}}_{\mathbf{93}}\text{Np} + ^{4}_{2}\text{He}$
  - *Check:* $241 = 237 + 4$; $95 = 93 + 2$
- **3b)** $^{\mathbf{90}}_{\mathbf{38}}\text{Sr} \rightarrow ^{90}_{39}\text{Y} + ^{0}_{-1}\text{e}$
  - *Check:* $90 = 90 + 0$; $38 = 39 + (-1)$
- **3c)** $^{137}_{55}\text{Cs} \rightarrow ^{\mathbf{137}}_{\mathbf{55}}\text{Cs} + \gamma$
  - *Check:* Gamma decay does not change $A$ or $Z$.
- **3d)** $^{\mathbf{209}}_{83}\text{Bi} \rightarrow ^{205}_{\mathbf{81}}\text{Tl} + ^{4}_{2}\text{He}$
  - *Check:* $209 = 205 + 4$; $83 = 81 + 2$
- **3e)** $^{210}_{\mathbf{84}}\text{Po}^* \rightarrow ^{\mathbf{206}}_{82}\mathbf{Pb} + ^{4}_{2}\text{He}$ *(worksheet prints `Pn` instead of `Po`)*
  - *Check:* $210 = 206 + 4$; $84 = 82 + 2$; Periodic Table $Z = 82 \rightarrow \mathbf{Pb}$ (Lead).
- **3f)** $^{\mathbf{40}}_{19}\text{K} \rightarrow ^{40}_{\mathbf{20}}\text{Ca} + ^{0}_{-1}\text{e}$
  - *Check:* $40 = 40 + 0$; $19 = 20 + (-1)$
